# Java Projects

This repository contains two Java projects created to practice core Java, arrays, object-oriented programming, GUI development, and basic artificial intelligence concepts.

A Java console-based application used to input and manage student grades.

## Features

* Input marks for multiple subjects
* Calculate average marks
* Find highest marks
* Find lowest marks
* Calculate grades
* Display a student summary report

## Concepts Used

# 2. Artificial Intelligence Chatbot

A simple Java-based rule-based chatbot with a graphical user interface.

## Features

* Interactive chatbot communication
* Java Swing GUI
* Rule-based responses
* Basic text processing
* Real-time user interaction

## Project Classes

* `MyChatbot.java` - Main class
* `ChatbotGUI.java` - Handles the GUI
* `DecisionEngine.java` - Contains chatbot rules and responses
* `TextProcessor.java` - Processes user input

## How It Works

```text id="m3h4p2"
User Input
    ↓
TextProcessor
    ↓
DecisionEngine
    ↓
Chatbot Response
    ↓
GUI Display
```



# Technologies Used

* Java
* Java Swing
* Object-Oriented Programming
* Arrays
* Rule-Based Logic
* Basic Text Processing

# How to Run

1. Clone or download this repository.
2. Open the project in VS Code or another Java IDE.
3. Compile the Java files.
4. Run the main class of the required project.
